# Site-Clincar
Site Institucional Clincar

Site estático (HTML, CSS e JavaScript), publicado no Netlify a partir da raiz do repositório.

- `index.html` — conteúdo e estrutura das seções
- `styles.css` — identidade visual e layout responsivo
- `script.js` — menu móvel, destaque do menu e animações
- `netlify.toml` — configuração de publicação

Para personalizar, procure no `index.html` pelos comentários `EDITAR:` e pelos itens marcados como **Provisório** / **Pendente**.
